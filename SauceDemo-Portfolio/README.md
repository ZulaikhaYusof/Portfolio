
# SauceDemo QA Project

This project contains my complete QA workflow for the **SauceDemo demo e-commerce site**. It demonstrates my skills in **manual functional testing, negative testing, test planning, and reporting**.

## Project Overview

- **Application:** SauceDemo (Demo E-commerce Site)  
- **Type:** QA / Functional Testing Practice  
- **Platforms Tested:** Web Browser  
- **Testing Focus:** Login, Product Sorting, Cart Operations, Checkout Flow, Menu Navigation  
- **Approach:** Manual testing with positive and negative scenarios, bug logging, and test documentation.
