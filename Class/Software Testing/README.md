# Shopee Website Testing – Group Project

This project involved **system testing of the Shopee e-commerce platform** to ensure functionality, usability, and performance.

## Features Tested
- User registration & login  
- Product search & filters  
- Cart management & checkout  
- Payment integration & order tracking  
- Ratings and reviews  

## Approach
- **Functional Testing:** Black-box techniques, decision tables, use cases  
- **Non-Functional Testing:** Performance tests during peak and off-peak hours  
- **Risk-Based Prioritization:** High, Medium, Low  

## Tools & Environment
- **Hardware:** Huawei Matebook D14 (Ryzen 7, 8GB RAM, SSD)  
- **Software:** Google Chrome, BlazeMeter  

## Outcomes
- High-risk features passed functional testing  
- System performed reliably under tested loads  
- Bugs identified and documented for improvement
